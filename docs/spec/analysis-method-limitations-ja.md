# 分析手法の限界

MeTheory の自己理解分析は、記録から再確認可能な傾向を見つけるための補助であり、因果関係・診断・固定的な人格特性を確定するものではない。

## 連続量の比較

選択式や真偽値はコホートに分けて比較する。機械計測の連続量どうしは、中央値で Low / High に二値化すると情報を失うため、別経路の Pearson 相関を使う。PCS の実データでは、AI 対話時間と DeepThinking 時間を観測時間で割った比率を、全期間・総観測時間が短い日・長い日に分けて出力する。

相関係数は線形な関連の要約であり、非線形な関係、外れ値、時間的な依存、交絡を解決しない。相関が出ても因果とは解釈しない。

## 交絡

2変数の比較だけでは、第三の変数による交絡を除けない。現在は総観測時間による一段階の層別を診断として出し、各層で方向が維持されるかを確認できる。これは回帰分析や多変量調整の代替ではない。

## 探索と再現

同じデータを見ながら許可ペア、期間、分割方式、効果量の扱いを変更すると、探索の自由度が増え、発見結果の有意性を過大評価し得る。Bonferroni 補正は候補生成時に数えた比較だけを補正し、開発中の探索履歴までは補正しない。

したがって、現在の55日分の結果は発見として扱う。次の新しい期間を別の検証期間として保存し、同じ方向が再現するかを確認する。再現しない場合も、期間依存の変化として記録する。

## 日次データの系列相関

同じ人の連続した日には系列相関があり、日を独立・交換可能とみなす順列検定の前提を満たさない可能性がある。現在はブロック順列検定を実装していないため、p値や有意性を過信しない。必要になった場合は、週単位などのブロックを保った検定を別の評価フェーズで導入する。

## 前半・後半の安定性

期間の前半と後半で方向が一致しても、時間トレンドを統制したことにはならない。AI 利用量や生活状況が期間中に変化した場合、「安定」ではなく「同じ方向のトレンド」が観測されているだけの可能性がある。temporalStability は再現性の補助指標として扱い、長期的な安定性の証明には使わない。

## 運用上の結論

分析結果には、使用期間、サンプル数、候補監査、感度情報、測定定義由来の交絡警告を併記する。結果を採用する前に、ユーザー確認と新しい期間での再検証を行う。
