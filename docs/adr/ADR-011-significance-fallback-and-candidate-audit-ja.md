# ADR-011: 大規模標本の有意性フォールバックと候補監査

## 背景
完全置換検定は組合せ爆発する。各コホート20件では全割当の列挙が現実的でなく、そこで`null`を返すとデータが増えただけで比較を捨てることになる。また、品質ゲート通過後に統計閾値で落ちた候補も監査できなければならない。

## 決定
200,000割当までは完全置換検定を使う。それを超える場合は10,000回の決定論的Monte Carlo置換検定とplus-one方式のp値推定を使い、方法を`monte_carlo_permutation`として保存する。完全検定とは表示しない。二値・2水準結果は正確な超幾何計算を使う。

候補監査には、Bonferroni補正に使った比較ファミリー数、サンプル・効果・バランス・欠損ゲート通過数、有意性で棄却された数、表示上限前の採用数を含める。通常の候補APIでは有意性ゲートを無効化できない。

連続数値の効果ゲートは、コホート平均差の絶対値をプール標準偏差で割るCohenのd風の標準化平均差を使う。0〜1440分のような広い宣言範囲には依存しない。コホート内分散が両方0の場合、分離が非ゼロなら最大の標準化効果、0なら0とする。

## 管理されたEvidence
効果ゲート通過後に有意性で棄却される数値比較を含む回帰Fixtureを用意する。実データの評価はPCSがレビュー済みのMarkdown由来Entryを提供した後に行う。これらは実ユーザーのEvidenceではなく、制御されたテストである。

## 時間安定性とコホート
時間安定性は全lookback期間ではなく、評価期間と候補の観測時刻の共通範囲を前半・後半に分ける。コホート境界はパラメータごとに`range_midpoint`、`observed_median`、`fixed_threshold`から選べる。PCSの連続機械計測は`observed_median`を使い、0〜1440分の管理範囲で片側に偏ることを防ぐ。

## 実機械計測の監査
最初のdev-pace実行はPCS V3で、55レコード・330個の利用可能な機械計測値を含んだ。3つの機械計測ロール群と24個の派生時間帯比較から27比較を監査し、効果ゲートを通過しなかったため、データ輸送失敗ではなくEvidence不足と判定した。時間別ベクトルは通常候補から除外し、別の機械計測フィールドとして保持する。
