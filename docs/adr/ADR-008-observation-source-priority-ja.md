# ADR-008: ユーザー観測とシステム観測を両方保持する

## 決定
同じフィールドとエピソードに複数の観測がある場合、評価器は`user_confirmed`、`system`、`ai_inferred`の順で使用する。同じソース内で競合した場合は、そのソースの最新観測を使う。これは製品挙動であり、自己申告の方が客観的に正確だと断定するものではない。

元観測のProvenanceは追記専用で保持する。システム値をユーザー値で削除・上書きせず、ユーザー値をAI推論で暗黙に置き換えない。将来の分析で不一致を示しても、取り込み時に一方を選んでソースを隠してはならない。

## 理由
MeTheoryは自己理解を分析するため、主観的な概念ではユーザーが確認した解釈を主な値とする。一方、決定論的なシステム計測値は監査と将来の不一致分析のために保持する。この優先順位は評価値の選択に限定され、AIが事実やEvidenceの強さを決めることを許可するものではない。

## 影響

- 優先順位と同率時のルールを文書化するため、評価結果を再現できる。
- ソース間の不一致を元観測から確認できる。
- 過去の元記録を変更せずに、将来の不一致表示機能を追加できる。
