# Closed-loop privacy boundary

Experiment observations contain typed outcomes, group keys, provenance, and
eligibility. They do not contain raw Markdown bodies. User scope is required
for every repository read and write.

Sensitive parameters remain subject to the existing parameter definitions,
consent, and external-AI access policy. Experiment-specific safety and stop
conditions are shown in the draft and are not decided by AI. No cloud sync or
external AI call is required for drafting, questions, evaluation, or freshness
review.

The evaluator uses deterministic aggregates and returns uncertainty,
missingness, adherence, and sensitivity information. It does not infer a
medical or psychological diagnosis, causal effect, or fixed personality. Self
Model updates require an explicit user action and are recorded as review
history.
