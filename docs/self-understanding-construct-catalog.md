# Self-understanding construct catalog

`uncategorized` is a valid v1 result. A candidate does not need a catalogued
construct to be generated or reviewed; classification can remain pending.

This catalog is the allowlist for MeTheory self-understanding analysis. A
construct is an observable, non-clinical comparison lens, never a diagnosis,
trait label, or medical inference.

| Key | Japanese label | Typical semantic roles |
| --- | --- | --- |
| `energy_level` | エネルギーの状態 | energy, fatigue, sleepiness |
| `recovery_conditions` | 回復しやすい条件 | recovery, sleep_quality |
| `task_initiation` | 作業を始める条件 | task_clarity, start_delay, initiation_difficulty |
| `task_continuation` | 作業を続ける条件 | continuation_difficulty, completion |
| `attention_conditions` | 集中しやすい条件 | focus, noise_level, environment |
| `motivation_conditions` | 取り組みやすい条件 | satisfaction, avoidance |
| `routine_stability` | 生活リズムの安定性 | time_of_day, day_type, sleep_duration |
| `decision_load` | 判断の負荷 | decision_count, uncertainty |
| `social_load` | 対人場面の負荷 | social_context, social_intensity |
| `environment_fit` | 環境との相性 | environment, noise_level |
| `uncertainty_load` | 曖昧さによる負荷 | uncertainty, deadline_clarity |
| `avoidance_pattern` | 回避が起きやすい条件 | avoidance, initiation_difficulty |
| `mood_conditions` | 気分が変わる条件 | mood, energy |
| `self_perception_gap` | 自己評価と記録のずれ | self_rating, observed_behavior |
| `state_dependent_tendency` | 状態によって変わる傾向 | condition and outcome pairs |
| `relatively_stable_tendency` | 比較的安定した傾向 | repeated period pairs |
| `uncategorized` | 要確認の比較候補 | other |

Semantic roles are suggestions. Ambiguous, sensitive, low-confidence, and
role-changing suggestions require user confirmation. Field pairs from different
templates are kept separate unless both fields explicitly allow a compatible
semantic merge. Unconfirmed or incompatible pairs are not aggregated together.

The analysis history determines scope: one period is `emerging`, repeated
consistent periods are `relatively_stable`, and conflicts remain
`state_dependent` or `uncertain`. A candidate shows supporting and
contradicting Entries, alternative explanations, missing data, and an
experiment; it never asserts a fixed identity.
